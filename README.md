# AFJDASHBOARD

## Overview

AFJDASHBOARD is a comprehensive web-based management information system designed for transportation and logistics companies. It integrates various aspects of business operations, including human resources, fleet management, route planning, and financial operations into a unified, user-friendly interface.

## Features

- **Main Dashboard**: Central hub providing an overview of key performance indicators (KPIs) across all departments.
- **HR Dashboard**: 
  - Employee information management
  - Attendance tracking
  - Leave request handling
  - Workforce analytics visualization
- **Fleet Dashboard**:
  - Vehicle status monitoring
  - Maintenance scheduling
  - Fuel consumption tracking
  - Interactive fleet performance visualizations
- **Routes Dashboard**:
  - Route planning and optimization
  - Performance tracking
  - On-time delivery monitoring
  - Incident management
  - Interactive route mapping
- **Finance Dashboard**:
  - Revenue trend analysis
  - Expense breakdown
  - Invoice management
  - Financial report generation

## Technologies Used

- Backend: Django
- Frontend: HTML5, CSS (Tailwind CSS), JavaScript
- Data Visualization: Chart.js
- Database: Sqllite
- Version Control: Git
